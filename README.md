# Τμήμα Ιστορίας και Αρχαιολογίας ΕΚΠΑ — πρόταση ανασχεδιασμού

Διαδραστικό πρωτότυπο για συζήτηση στο Τμήμα. **Δεν είναι η επίσημη ιστοσελίδα** του Τμήματος: <https://www.arch.uoa.gr/>.

Live preview: <https://ilicak.github.io/arch-ekpa-redesign/>

Redesign proposal for the Department of History and Archaeology, National and Kapodistrian University of Athens. Not the official website. The content is a snapshot of the official site taken on 22 October 2026.

## Notes

- Static site: no build step. GitHub Pages serves the files in this branch as they are.
- This copy is prepared for the `/arch-ekpa-redesign/` sub-path: internal links begin with `/arch-ekpa-redesign/`. The Netlify copy of the same site uses links that begin at `/`.
- Image credits: `ASSET_SOURCES.md`. Fonts: Noto Sans and Noto Serif (SIL Open Font License, in `assets/`).
- Pages carry `noindex` so search engines do not list the prototype.
